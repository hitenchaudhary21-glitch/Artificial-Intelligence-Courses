# Prerequisites

---

## What You Need to Know Before Starting

The short answer: **almost nothing.**

*Artificial Intelligence: From Zero to Mastery* is designed to start from the very beginning. You do not need a degree in computer science. You do not need to be a mathematician. You do not need years of programming experience. This book builds every concept from the ground up, explaining each idea as it appears and never assuming knowledge that has not already been covered.

If you can read this page, you have enough to begin.

## Basic Computer Literacy

The one genuine prerequisite is basic familiarity with using a computer. You should be comfortable with:

- Navigating files and folders on your computer.
- Using a web browser to search for information.
- Installing software and applications.
- Typing and basic text editing.

If you use a computer for everyday tasks — email, browsing, documents — you already have the skills you need. The book will guide you through anything more specific as it arises.

## Optional: Programming Knowledge

Programming experience is **helpful but not required** to get started. The conceptual chapters (Parts 1–3) require no coding at all. When we reach the hands-on material in Parts 4–7, basic familiarity with a programming language — particularly **Python** — will make the practical exercises smoother.

If you have never written a line of code, do not worry. The book introduces programming concepts gently and provides references to beginner-friendly resources. Many readers choose to learn Python alongside this book, and that approach works very well.

If you already know Python or another programming language, you will be able to dive into the practical exercises immediately and get the most from the project chapters.

## Tools You Will Need

To follow along with this book, you will need:

- **A computer** — Windows, macOS, or Linux. Any modern machine will work. You do not need a powerful GPU to get started; cloud-based tools can handle the heavy lifting when needed.
- **An internet connection** — for accessing online resources, datasets, and cloud-based AI tools referenced throughout the book.
- **A text editor or IDE** — such as Visual Studio Code (free), which we recommend for its simplicity and excellent support for Python and AI-related tools.
- **A notebook** (physical or digital) — for taking notes, writing summaries, and completing the Teach steps in each chapter.

As you progress through the book, we will introduce additional tools and platforms — such as Jupyter Notebooks, Google Colab, and various AI APIs — with clear setup instructions at the point where they are needed.

## The Most Important Prerequisite: A Growth Mindset

More than any technical skill, the most valuable thing you can bring to this book is a willingness to learn. AI is a vast and evolving field. There will be moments of confusion, concepts that require multiple readings, and exercises that challenge you. That is not a sign that you are failing — it is a sign that you are growing.

Approach each chapter with curiosity rather than anxiety. Celebrate small victories. Ask questions. Revisit material when needed. Trust that understanding builds over time, layer by layer, and that every page you read brings you closer to mastery.

You do not need to be brilliant to learn AI. You need to be persistent, curious, and willing to engage. If you have those qualities, you have everything you need.
